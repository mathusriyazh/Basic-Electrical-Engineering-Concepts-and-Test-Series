Important Formulae
RMS value of sine wave: Vrms = Vm/√2
Average value of half-wave rectified sine: Vavg = Vm/π
Average value of full-wave rectified sine: Vavg = 2Vm/π
Form Factor: Form Factor = RMS Value / Average Value
Peak Factor: Peak Factor = Maximum Value / RMS Value
For a sine wave: Form Factor = 1.11
For a sine wave: Peak Factor = √2 = 1.414
